# 🍽️ Expanilla Food

[![Minecraft Version](https://img.shields.io/badge/Minecraft-26.1+-brightgreen.svg)](https://www.minecraft.net/)
[![Fabric](https://img.shields.io/badge/Loader-Fabric-blue.svg)](https://fabricmc.net/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A culinary mod for Minecraft (Fabric) that adds over 30 dishes and drinks, all crafted using vanilla ingredients. Some dishes provides its own temporary buffs (Speed, Regeneration, Night Vision, Fire Resistance, and more).

Supports [LambDynamicLights](https://modrinth.com/mod/lambdynamiclights)
